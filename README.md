Descripción del proyecto
Este repositorio contiene cuatro programas independientes en Python para calcular y verificar recursos necesarios en una misión espacial y determinar si se puede autorizar inicialmente el lanzamiento.
Programas incluidos
Archivo	Ejercicio	Descripción
ejercicio1_recursos.py	1. Cálculo de recursos	Calcula combustible, oxígeno, energía y provisiones necesarios para una misión.
ejercicio2_combustible.py	2. Verificación de combustible	Calcula el combustible total y el adicional; advierte cuando el margen es inferior a 10 unidades.
ejercicio3_soporte_tripulacion.py	3. Verificación del soporte para la tripulación	Comprueba si el oxígeno y las provisiones disponibles cubren las cantidades requeridas.
ejercicio4_autorizacion.py	4. Autorización inicial de lanzamiento	Autoriza el lanzamiento solo si combustible, oxígeno, energía y provisiones son suficientes.
